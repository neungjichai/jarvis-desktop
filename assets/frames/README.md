# 캐릭터 프레임 이미지

이 폴더에 상태별 하위 폴더를 만들고 **128×128 투명 PNG**를 넣으면, 코드로 그린 기본 캐릭터 대신 그 이미지를 씁니다 (Shimeji-ee 프레임 규격 참고).

```
frames/
  walk/      0.png 1.png 2.png ...   걷기
  sit/       0.png ...               앉기
  pet/       0.png ...               쓰다듬기
  notify/    0.png ...               알림
  thinking/  0.png ...               응답 중
  error/     0.png ...               오류
```

- 파일 이름 순서(숫자 정렬)대로 초당 8장 속도로 재생합니다 (`FRAME_FPS`, `src/renderer/renderer.js`).
- 이미지는 **왼쪽을 바라보는 모습**으로 그립니다. 오른쪽으로 걸을 때는 자동으로 좌우 반전합니다.
- 캐릭터 발이 이미지 맨 아래에 닿도록 그려야 작업 표시줄 위에 서 있는 것처럼 보입니다.
- 폴더가 없거나 비어 있는 상태만 기본 캐릭터로 그립니다. 상태별로 하나씩 교체해도 됩니다.
- Leonardo AI 등으로 만든 이미지는 프롬프트·출처를 출처 문서에 기록합니다 (PSR-001).
